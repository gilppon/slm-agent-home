확인된 패키징·라이선스 사실과 아직 검증하지 않은 통합 경계를 구분합니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • 포터블 아티팩트는 Windows x64 대상이며 Python 3.13.16 런타임을 번들링합니다.
  • 라이선스 verifier는 서명, 에디션, 유효 기간, 장치 식별값을 검사합니다.
  • Worker는 로컬 Wrangler dry-run까지만 확인했고 production 배포는 하지 않았습니다.

아직 검증되지 않은 점

  • 빌더·모델·RAG·API·런처를 고객 환경에서 연결한 전체 흐름은 검증되지 않았습니다.
  • 지원 모델/API 조합, GPU 성능, 동시성, 장애 복구 기준은 미정입니다.
  • 외부 송신을 독립적으로 추적하거나 차단한 결과가 없습니다.

평가 전에 합의할 범위

  • 구성요소와 버전/해시 목록
  • 실행 프로세스·파일·서비스·포트 흐름
  • 모델 저장소와 선택적 외부 API 의존성
  • 관찰 가능한 로그와 합격/중단 조건
