라이선스 | 서명·검증 기술 경계

현재 구현된 토큰 검증 항목과 발급자 키 관리의 운영 위험을 함께 공개합니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • 토큰은 KODARI2.<payload>.<signature> 형식입니다.
  • 서명, 에디션, 발급/만료 시각, 장치 ID 파생값을 검증합니다.
  • Windows 컴퓨터 제품 UUID를 우선 사용하고 MachineGuid를 대체값으로 사용합니다.

아직 검증되지 않은 점

  • 잘못된 서명·만료·다른 장치·에디션 불일치·키 교체를 포함한 전체 수명주기 시험이 남아 있습니다.
  • 현재 발급자 PEM은 암호화되지 않은 형식으로 읽으므로 계정/파일 접근 보호가 중요합니다.
  • 로컬 관리자 또는 수정된 클라이언트가 검사를 우회할 가능성을 제거하지 못합니다.

평가 전에 합의할 범위

  • 유효/변조/만료/타 장치/잘못된 에디션 시험 사례
  • 시스템 시각 변경과 ID 변경 동작
  • 개인키 권한·보호 백업·회전·폐기 절차
  • 검증 실패 시 fail-closed 동작과 운영 지원

다음 판단

발급 키는 제품 밖에서 제한된 접근으로 보관합니다. 고객에게 복사·역공학 방지가 보장된다고 설명하지 않습니다.
