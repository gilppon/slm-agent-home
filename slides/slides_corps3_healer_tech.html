문서 업무 평가 | 기술 검증 계획

문서 수집에서 답변 검토까지 데이터 경로, 오류 유형, 보존 조건을 측정하는 계획입니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • 현재 검증된 산출물 검사는 ZIP 및 런타임 파일 수준입니다.
  • 문서 파싱·임베딩·검색·답변·감사 로그의 고객 종단 간 시험은 완료되지 않았습니다.
  • PII 보호, 완전 삭제, 감사 인증 결과는 현재 제공되지 않습니다.

아직 검증되지 않은 점

  • 지원 파일 형식별 파싱 정확도와 대용량/손상 문서 동작
  • 검색 재현율·정밀도, 답변 근거성, 오답률 및 평가 데이터셋
  • 저장 위치·캐시·로그·백업에서의 데이터 보존/삭제 범위

평가 전에 합의할 범위

  • 문서 유형·언어·규모와 비식별 평가셋
  • 정답 라벨과 허용 가능한 오류 기준
  • 데이터 흐름도와 저장·로그·삭제 확인
  • 수동 승인과 실패 격리/재처리 절차
