Windows 포터블 빌드 | 기술 검증 항목

런타임 동봉과 아카이브 검사는 완료했지만, 모델 기능을 포함한 재현 가능한 고객 설치 검증은 남아 있습니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • 번들 런타임 버전은 Python 3.13.16입니다.
  • 세 언어 ZIP의 무결성과 번들 런타임 파일 존재를 확인했습니다.
  • Python 3.13은 Windows 7 이하를 지원하지 않습니다.

아직 검증되지 않은 점

  • 지원 OS 기준선과 GPU/드라이버 조합을 확정하지 않았습니다.
  • ML 의존성/API 조합은 모델 학습·추론 경로까지 호환 검증되지 않았습니다.
  • 고객 환경에서 설치, 업데이트, 롤백, 복구를 수행하지 않았습니다.

평가 전에 합의할 범위

  • OS/드라이버/런타임 버전 고정
  • 깨끗한 Windows 계정에서 압축 해제 후 실행
  • 모델 로드·추론·학습의 재현 절차
  • 실패 로그, 정리·복구, 데이터 보존 확인
