네트워크·배포 | 사전 검토 안내

현재 확인된 것은 로컬 Worker dry-run까지이며, production 배포나 폐쇄망 운영은 확인되지 않았습니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • Worker 설정은 로컬 Wrangler dry-run에서 확인했습니다.
  • Cloudflare production 배포, 고객 도메인/라우팅, 운영 secret 등록은 수행하지 않았습니다.
  • 로컬 실행 여부만으로 전체 구성의 외부 통신이 없다고 결론낼 수 없습니다.

아직 검증되지 않은 점

  • 제품 전체의 네트워크 연결 목록과 외부 송신량을 독립 추적하지 않았습니다.
  • 방화벽 예외·외부 바인딩을 적용하는 고객 배포 절차가 검증되지 않았습니다.
  • 에어갭 인증, zero-egress, 무유출 보장은 존재하지 않습니다.

평가 전에 합의할 범위

  • 필요한 호스트·포트·프로토콜·방향과 목적
  • 모델/패키지 다운로드 및 선택적 API 경로
  • 허용된 시험망에서의 패킷·프로세스 관찰
  • 기본 차단 정책, 예외 승인, 중단·복구 절차

다음 판단

실제 네트워크 요구사항을 목록화하고 제한된 환경에서 측정한 뒤 구성별 결과를 검토합니다. 검증 전에는 외부 접속 차단이나 사내망 공개 설정을 안내하지 않습니다.
