Windows 포터블 빌드 | 평가 안내

현재 확인된 것은 배포 아카이브의 구성과 무결성입니다. 고객 PC에서의 제품 기능 검증은 별도 단계입니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • Windows x64용 포터블 패키지에 Python 3.13.16 임베더블 런타임이 포함됩니다.
  • KO·EN·JA ZIP 3개가 각각 전체 무결성 검사를 통과했습니다.
  • 포터블 런처는 번들 런타임 사용 시 사용자 site 경로와 PYTHONPATH 오염을 정리합니다.

아직 검증되지 않은 점

  • 고객 PC 설치·실행, GPU 호환성, 모델 다운로드/로드를 확인하지 않았습니다.
  • Standalone Setup.exe, 서명된 설치 프로그램, 자동 업데이트는 검증된 제공물이 아닙니다.
  • 최소 Windows 버전과 지원 GPU 목록은 확정되지 않았습니다.

평가 전에 합의할 범위

  • Windows 빌드와 보안 업데이트 수준
  • CPU/GPU 모델, VRAM, RAM, 저장 공간
  • 모델 파일 출처와 용량
  • 설치·실행·제거·복구에 필요한 관리자 권한

다음 판단

포터블 ZIP은 내부 검증 산출물입니다. 고객 제공 전 대표 장비에서 설치·실행과 복구를 확인해야 합니다.
