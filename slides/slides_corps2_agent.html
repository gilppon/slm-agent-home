라이선스 | 장치 바인딩 평가 안내

라이선스 토큰의 장치 연결 흐름과 운영상 제한을 설명합니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • 검증 빌드는 Ed25519 서명 토큰 형식 KODARI2를 사용합니다.
  • 발급에는 고객 장치에서 수집한 HW-ID가 필요하며 자동 온라인 발급은 없습니다.
  • 다른 장치에는 해당 장치 식별값으로 별도 토큰을 발급해야 합니다.

아직 검증되지 않은 점

  • HW-ID 수집부터 발급·설치·만료·장치 교체까지 전체 고객 절차를 검증하지 않았습니다.
  • 개인키 회전·복구 및 분실 대응 절차는 출시 준비가 필요합니다.
  • 장치 바인딩은 소프트웨어 통제이며 변조 방지 하드웨어 DRM이 아닙니다.

평가 전에 합의할 범위

  • 장치 식별값 전달을 위한 승인된 보안 채널
  • 토큰 대상 장치·에디션·유효 기간
  • 만료·재발급·장치 교체 승인 절차
  • 발급자 키 접근 통제와 보호 백업

다음 판단

토큰 발급 전에 장치 ID 취급과 재발급 절차를 합의합니다. 개인키는 제품·고객 패키지·영업 채널에 넣지 않습니다.
