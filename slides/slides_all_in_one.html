KODARI 로컬 AI 검증 빌드 | 평가 개요

Windows x64 포터블 로컬 AI 빌드의 현재 상태와 제한 평가에 필요한 확인 항목을 정리합니다.

현재 상태: 내부 Windows x64 포터블 검증 빌드

확인된 사실

  • Windows x64 포터블 패키지에 Python 3.13.16 임베더블 런타임이 포함됩니다.
  • KO·EN·JA ZIP은 전체 무결성 검사를 통과했습니다. 이는 압축 파일의 읽기 가능성만 확인합니다.
  • 라이선스는 Ed25519 서명 및 장치 식별값에 연결된 토큰을 사용합니다.

아직 검증되지 않은 점

  • 고객 장비에서 설치·모델 로드·추론·학습·복구를 완료하지 않았습니다.
  • 성능, 지원 하드웨어, 네트워크 송신 동작, 상용 지원 조건은 확정되지 않았습니다.
  • 제품 통합 시나리오의 고객 환경 종단 간 검증이 남아 있습니다.

평가 전에 합의할 범위

  • 대상 Windows 버전과 CPU/GPU·메모리
  • 사용할 모델·업무 시나리오와 승인된 데이터
  • 네트워크 정책과 허용/차단할 통신 경로
  • 기간·성공 기준·로그/오류 처리 방식
